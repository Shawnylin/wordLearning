## 后续 AI 修改时推荐的命令

常规逻辑改动：

```sh
npm run check
npm run build
```

涉及同步、服务商设置、日报历史、弹层、生成结果时，再运行：

```sh
npm run test:browser
```

首次安装 browser 环境：`npm ci` 后执行 `npx playwright install chromium`。Windows 可用 `$env:BROWSER_CHANNEL = 'msedge'` 指定已有 Edge。只改一个流程时可运行 `node tests/run-browser.mjs daily-smoke` 等相应脚本。

CSS 修改应在修改前运行 `npm run test:visual:baseline`，修改后运行 `npm run test:visual`，再比对 `docs/.local/css-refactor/` 内对应 PNG。不把事后截图作为“修改前”基线。

失败后只重跑受影响的检查；必要时最后确认统一入口。已通过且无相关变化的检查无需反复运行。若环境缺浏览器/真实设备/账户，报告未验证范围与最小手动步骤，不把未执行写成通过。
