# 模型设置与加密同步（0.9.0）

## 使用

- 在“模型与 API”添加服务商，填写地址与 Key，获取列表后即可保存，不必选择用途模型；接口没有列表时可以补充模型名称。
- 学习、PDF 和 MiMo 朗读分别选择服务商下的模型。修改服务商凭据会更新已关联的用途，删除服务商会清除这些用途的凭据。
- 在个人页“云同步 → API 加密同步”设置独立同步口令，至少 12 个字符。新设备登录同一账号后，输入口令恢复配置；可记住此设备。
- 遗忘口令无法解密。忘记设备解锁密钥不会删除本机 API 配置。

## 加密与同步边界

- Web Crypto：PBKDF2-SHA256（600,000 次，16 字节随机盐）派生 AES-256-GCM 密钥，每次加密使用新的 12 字节 IV。
- API 配置整体加密，包括服务商列表、Key、模型用途、朗读设置和思考设置。账号 ID、格式版本及更新时间纳入认证数据，跨账号替换、密文篡改或时间篡改不能通过解密。
- 云端沿用 `user_sync_snapshots.payload.apiSettings` 保存密文，无需数据库迁移；口令和解密密钥不会上传。
- “记住此设备”将不可导出的 CryptoKey 保存在 IndexedDB，不保存口令。关闭记住或忘记设备时删除该密钥。
- 本机仍保留可用的离线 API 配置（现有 `settings-store`）；这不是防御本机恶意软件或同源脚本的密码库。云端只有密文。
- 配置作为整体按修改时间合并；未解锁的设备保留已有密文，不用空配置覆盖。切换账号时清除前一账号的活动凭据。
- 旧版学习快照可以继续读取。建议参与 API 同步的设备均更新至 0.9.0，旧客户端不识别加密配置字段。

## 余额支持

每个服务商单独一行显示金额或查询状态，同地址同 Key 去重；单个查询失败不影响其他行。

MiMo 的[公开 API 参考](https://mimo.mi.com/docs/en-US/api/guidance/rate-limit)未列出 API Key 余额查询接口，[官方付款说明](https://mimo.mi.com/docs/en-US/quick-start/faq/payment)指向控制台余额页。本次提供“在 MiMo 查看”入口，不猜测接口、不采集小米账号 Cookie，也不展示虚构数值。MiMo 数字余额自动查询尚未实现。

## 已验证

- 生产类型检查和构建。
- 加密往返、错误口令、账号与时间绑定、随机 IV、损坏密文格式拒绝。
- Edge 浏览器：按钮圆形起点、动画中间尺寸、快速关闭反向衔接、减弱动态效果；320px、393px、1280px 布局。
- 获取两个模型后无需选择模型即可保存；一份 MiMo 凭据分别用于 PDF 与朗读；朗读三个操作同排；多个服务商余额及 MiMo 官方入口。
- 两个隔离浏览器环境模拟新设备恢复；Key 修改联动、账号切换隔离、记住设备后重新加载。
- 个人页开启加密同步、忘记设备、错误口令提示；拦截 CloudBase 写入检查，上传内容不含测试 Key 或口令明文。
- 只读核对线上表结构、RLS 启用状态，以及 SELECT / INSERT / UPDATE / DELETE 均使用 `user_id = auth.uid()`。

自动化入口：`tests/api-vault.test.mjs`、`tests/settings-browser.mjs`、`tests/api-vault-browser.mjs`、`tests/settings-sync-ui.mjs`。浏览器测试使用本机 Vite 5174 端口及模拟账号/API；Playwright 可从项目依赖或 `CODEX_NODE_MODULES` 加载。截图写入忽略目录 `docs/.local/`。

## 未验证与最小人工验收

未使用真实 API Key、用户账号或付费模型调用；CloudBase 写入与恢复使用模拟响应，线上只做权限和结构读取。未部署或推送。

1. 设备 A 登录自己的账号，配置服务商，开启加密同步并完成“立即同步”。预期状态为“已同步”，API 为“已解锁”。妥善保存口令。
2. 设备 B 更新到本版本，登录同一账号，输入同步口令。预期恢复服务商及各用途模型；错误口令不会覆盖本机配置。
3. 使用自己的 MiMo Key 获取模型列表、选择相应 PDF / 语音模型，解析一份短 PDF 并试听一句话。预期两个功能共用同一份凭据；调用可能产生服务商费用。
4. 在真实手机上打开、快速收回服务商弹层。预期圆形起点位于按钮，关闭回到原按钮，操作按钮无空列或遮挡。
